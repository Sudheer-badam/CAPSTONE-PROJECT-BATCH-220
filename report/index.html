AI-Based Social Media Sentiment & Trend Analysis Platform
On Women Safety

A deep-learning powered platform that collects, processes, and analyses social media data to detect sentiment trends related to women's safety using NLP and transformer-based models.

Batch 220 KL University NLP - BERT - VADER 202627
Project Report Overview
Key highlights from our capstone project -- AI-Based Social Media Sentiment & Trend Analysis Platform on Women Safety

Problem Statement

Social media generates massive unstructured data daily. Manually analysing this for women's safety concerns is impractical. An AI-powered automated pipeline is required to detect, classify, and visualise safety-related sentiments in real time.

Objectives

Collect real-time social media posts, apply NLP preprocessing, classify sentiments (Positive / Negative / Neutral), detect trending topics, and present insights through an interactive dashboard.

Technology Stack

Python - Firebase - Twitter/Reddit APIs - VADER - TextBlob - BERT Transformers - Matplotlib - Vercel Deployment - HTML/CSS/JS Dashboard.

Methodology

Data Collection -> Preprocessing (tokenisation, stopword removal, lemmatisation) -> Sentiment Classification -> Trend Detection -> Visualisation -> Deployment.

Results & Accuracy

BERT-based classification achieved ~91% accuracy on labelled datasets. VADER and TextBlob provided fast real-time analysis. Dashboard visualises live sentiment distribution and trending hashtags.

Impact & Conclusion

The platform empowers authorities, researchers, and NGOs to monitor and respond to women's safety concerns on social media -- enabling faster, data-driven decision making.
